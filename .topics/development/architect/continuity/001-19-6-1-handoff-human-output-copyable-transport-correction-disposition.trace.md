# Handoff human output copyable transport correction disposition

## Decision

- State: accepted
- Subject: current ChatGPT-host human-output contract for qualified Role-to-Role Handoff dispatch

No recurring portable Tooling defect is established and no Loom implementation task is authorized by this correction.
- Cold-Start Rule: before emitting a Handoff, the active Role must regenerate or inspect `project-handoff-carrier-output` for the selected route, require `humanOutput.status: ready`, surface the `primary` carrier as the sole normal file choice, and render the package-derived minimal routing text immediately adjacent in a fenced/copyable block. Do not reconstruct the locator from chat memory or outer filename.
- Trust Level: accepted local host/output discipline / package-derived projection / no Handoff semantic authority / no portable Tooling mutation
