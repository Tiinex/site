# Tooling 015 Anchor acceptance

## Decision

- State: accepted-bounded
- Subject: multi-root Handoff workspace manufacturing and operator-input closure
- Decision: accept Tooling 015 at the functional portable Tooling boundary. The normal Node/CLI path now accepts explicit 1..N local workspace roots, preserves the single-root default, binds routes to explicit workspace ids, rejects duplicate/unavailable roots, preserves source-neutral carriage, and reuses the existing plural package model rather than introducing a second representation.
- Performance Boundary: this acceptance does not declare the full-workspace path ergonomic or close the earlier scaling contradiction. The prior approximately 30 MB fixture is unavailable, so the exact greater-than-180-second observation cannot be remeasured. On the current carried Site bytes, Anchor independently measured deterministic workspace enumeration at 3,686 ms for 1,389 regular files / 9,841,848 bytes and embedded Tooling-bootstrap enumeration at 773 ms for 303 runtime files / 2,934,345 bytes, while both normal manufacture and explicit `--no-roundtrip` manufacture failed to complete inside the current host's 45-second execution window. That is new current-host operational evidence, not proof that Tooling 015 caused the cost.
- Trust Level: bounded functional acceptance / performance non-closure / no source-authority promotion

## Basis

- Independent reruns pass `multiRootManufacture.test.mjs`, the aggregate `portable.test.mjs` suite, `validate-static.mjs`, and `portable:smoke`.
- The returned implementation preserves route membership as `(workspaceId, workspace-relative Handoff path)` and the focused regression proves a route may live only in a secondary workspace without silently manufacturing a primary route.
- The returned scale test passes its available synthetic 1,286-carrier fixture, but the exact larger historical fixture required by the original warning is not present. The returned result correctly withholds a universal performance claim.
- The current Anchor replay further shows that file enumeration and Tooling-bootstrap discovery are not themselves the whole observed cost on the carried Site fixture. Root cause is not established and no speculative optimization is accepted here.

## Consequences

- Tooling 015 is closed as a bounded functional implementation result.
- Preserve the historical larger-fixture scaling contradiction and the new current-host greater-than-45-second normal-path evidence as unresolved operational performance evidence. Neither may be rewritten as a solved SLA.
- Do not make performance investigation part of the immediate human-output correction unless that correction materially worsens or directly owns the observed cost. A separately controlled scaling leaf may be opened when the trust tranche needs normal full-workspace manufacturing on this host or when phase evidence can isolate a reproducible owner.
- No canonical Workspace/Source/Handoff semantics, Viewer behavior, publication state, or source authority changes are accepted by this decision.

## Review Conditions

Reopen the functional acceptance only for a reproducible contradiction in 1..N root enumeration, workspace-id qualification, route binding, binary/symlink handling, one-root compatibility, or package verification. Track the unresolved manufacturing cost separately until exact phase evidence identifies a bounded owner.
