## Manual Test Frontier

- Open representative Business, Docs, and Site material in Feed and interact with filters, scrolling, focus, artifact opening, column controls, and ordinary Viewer chrome. Compare perceived response with the prior checkpoint; specifically watch for the former multi-second freeze after Docs joins.
- While interacting, verify no unexpected source refresh/materialization indicator appears merely from hover, pause, selection, or scrolling. If a network/profiler tool is available, capture any residual repeated call before changing adapters.
- Enter Playthings with the same material. Let playback run, pause it, open Tech Tree/skills, hover multiple leaves, click controls, and test hotbar paths. The prior pause/Live transition-qualification freeze should no longer scale across the whole living population.
- Toggle Follow during an already-running travel event and again before a new event. Camera should follow the current active Plaything while wheel zoom remains free; pausing should release the active follow lock.
- Use Fit World at sparse and dense playheads. Camera controls should respond promptly and frame current visible world content rather than being swallowed by drag or UI stall.
- Click living Playthings/structures after panning and confirm detailed artifact opening remains available.
- In normal Viewer, drop a single artifact onto a specific workspace. Confirm only that workspace receives it.
- In normal Viewer, drop an ordinary ZIP onto a specific workspace. Confirm its local material goes into that workspace.
- Drop a single artifact or ordinary ZIP outside every workspace column. Confirm a new workspace opens and receives the material; the previously active workspace must not silently receive it.
- Drop the current Handoff package anywhere in Viewer. Confirm its Business/Docs/Site workspaces reconcile globally: existing matching workspaces update rather than duplicate, missing package workspaces are added, and unrelated open workspaces remain.
- Drop the same Handoff package again. Confirm the same qualified workspace identities are replaced/reconciled rather than producing duplicate Business/Docs/Site columns.
- Enter Playthings and drop a Handoff package directly on the world. Confirm Playthings does not force an exit to Viewer, the package is treated globally, compatible current world/camera state remains present, and newly observed suffix material can play from the prior observation toward the new Now.
- While historically paused in Playthings, drop a package that adds newer material. Confirm the current historical playhead is not rewritten to Now merely because import occurred; the later material remains future suffix until playback reaches it.
- If a package materially changes an already-observed prefix/Parent resolution, confirm the system rebuilds/requalifies rather than pretending the change was only a suffix.
- Drop an ordinary artifact/ZIP directly on Playthings. Confirm it is treated as global/outside material and creates a new workspace behind the shared world rather than mutating an arbitrary active workspace.
- Reload the page after a transient package-only session and observe the explicit current persistence behavior; do not treat failure to durably recover package snapshots as data loss because this checkpoint intentionally avoids claiming durable package preservation.
