# Playthings organic world, live tools, and schema Tech Tree refinement

## Objective

Continue the co-designed Playthings projection without introducing a Playthings semantic monolith: make deterministic placement feel organically grown rather than grid-arranged; make active lineage easier to follow; restore Fit World and artifact-detail interaction; give schema artifacts a separate retro blueprint/Tech Tree surface; add lightweight local player progression and a hotbar over existing canonical Tiinex creation flows; represent fast-project leaf inactivity relative to the historical playhead; and extend the presentation grammar for Workspace, Signal, Feedback, Schema, and the registered Site artifact kinds.

## Done Criteria

- All loaded workspaces/origins continue to coexist on one shared earth; neither repository nor Workspace becomes a separate island or semantic world.
- Placement stays deterministic and prefix-stable but no longer projects onto the prior regular grid/sphere pattern; namespaced checksum-derived entropy varies scan direction, tie-breaking, sprite variation, and other presentation-equivalent choices.
- A sibling branch preserves the already-living leaf as occupied space while the new branch returns through its actual branch context and finds its own nearest valid presentation location.
- Place artifacts provide only a soft local placement incentive for descendants; they do not magnetically own descendants or infer undeclared containment.
- Organization remains a history-built settlement place; Workspace may become a history-built workshop/hamlet whose building count is bounded by actually represented Workspace material rather than guessed importance.
- Signal is presented as a bounded call with ripple-like wave rings; Feedback is a communication scene; unknown participants are never fabricated.
- Schema artifacts are blueprint scenes and are additionally projected into a separate retro Schema Tech Tree.
- Schema Tech Tree distinguishes Site-implemented schemas from observed schemas unavailable in this Site build; unavailable observed schemas remain openable but show locked / not yet implemented presentation state.
- Abstract schemas can participate in Tech Tree progression but cannot yield a Create skill.
- Initial Tech Tree friction is intentionally light: Open marks a schema as locally inspected; Upgrade unlocks a creatable skill; holding Shift may quick-upgrade an otherwise upgradeable schema without the Open step.
- Playthings profile/progression state, including inspected/upgraded schema ids, Follow preference, and hotbar assignment, is stored only in localStorage as disposable UI state; it must not use qualifications or become Tiinex semantic history.
- Unlocked Create skills can be placed in a six-slot hotbar; click or number key reuses the existing canonical Viewer Create flow rather than a Playthings-specific artifact editor.
- Hovering a living Plaything while tools are available may show only the intersection of Viewer-qualified valid transitions and locally unlocked creatable skills; Playthings never invents transition validity.
- Follow Plaything can lock camera center to the active travelling Plaything during playback while keeping wheel zoom available; manual pan remains available when Follow is not actively locked.
- Fit World computes bounds from currently visible structures, leaves, and active motion rather than the whole empty earth or hidden resting actors.
- Clicking a living leaf or persistent structure again opens the owning artifact in the existing detailed Viewer surface without camera drag swallowing the click.
- Playback time is relative: the current artifact event supplies historical playhead time while playback/paused history is being viewed; settled Now switches to Live time.
- Hotbar and Tech Tree are available only while playback is paused or at settled Live/Now.
- Artifacts created from paused or Live Playthings tools always use the canonical current-time creation path; no historical/improvised timestamp is generated from the Playthings playhead.
- Direct local Create suffix material can be incorporated as a new real-Now timeline suffix; when created from Live it may play as a new event, while paused historical playback remains historical.
- Leaf inactivity is presentation-relative to playhead: under four relative days is normal, four through seven days is long-idle, and greater than seven days is resting.
- A resting Plaything uses the nearest already-built legitimate habitat when one exists; it is visually compressed into that settlement and can wake from a habitat when later observed history continues its lineage. No habitat is invented solely to hide an idle leaf.
- Pausing playback freezes requestAnimationFrame motion and CSS action texture, including Signal ripple animation.
- Existing Tiinex Parent, Relation, schema capability, creation, transition, identity, provenance, evidence, validation, and unknown-state semantics remain authoritative; Playthings adds only presentation and local affordance state.
- Implementation remains decomposed across world, clock, profile, Tech Tree, progression UI, camera, motion, presentation companions, artwork, renderer, and a thin app interaction bridge rather than growing TiinexApp or Playthings into a monolith.
