# Playthings Development Root

## Purpose

All new Playthings development lineage belongs under `.topics/viewer/playthings/` rather than directly under `.topics/viewer/`.

This root owns the current consolidation/runtime-rebase branch while graphics source lineage and production-process lineage remain in their dedicated sibling folders.

## Active Structure

```text
.topics/viewer/playthings/
├─ development/
├─ graphics/
└─ processes/
```

The old Viewer-root iteration history has been reduced into a compact Evidence under `development/`; it is not re-copied into an archive folder.

## Boundary

This Topic organizes Playthings development provenance only. Final schema-bound runtime companions live beside their schemas under `src/schemas/`, and current runtime code remains under `src/experiments/playthings/` until a reviewed rebase slice replaces it.
