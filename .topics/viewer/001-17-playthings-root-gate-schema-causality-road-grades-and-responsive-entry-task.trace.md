# Playthings Root Gate, schema causality, road grades, and responsive entry

## Objective

Make the shared-earth fantasy presentation obey a clearer Tiinex-first causal grammar: schema documents remain blueprints rather than living Playthings or traffic sources; living roots with no already-observed lineage place emerge from one neutral presentation-only Root Gate instead of materializing from arbitrary grass; road wear matures through deterministic levels 1-10 and meaningfully reduces travel cost; navigation avoids current Playthings and structures without collapsing all traffic onto one mathematical corridor; Playthings Lineage Verse keeps latest/current at the top with Parent falling downward; and entering Playthings paints immediately before expensive projection/world work runs away from the UI thread.

## Done Criteria

- A canonical .schema.md document is classified from its durable material path, including path, sourcePath, source.path, sourceTarget.sourceArtifactPath, or snapshot.sourceArtifactPath carriage, rather than from the schema it describes.
- Schema documents remain observable blueprint/history events and Tech Tree material but cannot become living Plaything actors, persistent structures, habitats, traffic sources, or living-leaf terminators.
- A real descendant whose semantic Parent chain passes through one or more schema documents continues physically from the nearest earlier real living ancestor without rewriting the actual Tiinex Parent edge.
- A real living root with no already-observed ancestor place originates from one shared Root Gate in the world and visibly travels from that gate to its generated scene.
- Root Gate is presentation-only and cannot become Parent, Relation, Organization, Workspace, semantic place, habitat, membership, or authority.
- Root Gate generation is prefix-stable and uses one shared-earth coordinate rather than repo islands or arbitrary per-root spawn points.
- Completed traffic accumulates deterministic road maturity from level 1 through level 10, with visual width/color/decorative treatment able to evolve by level.
- Grass remains more expensive than mature roads in A*; a longer established corridor may beat a geometrically shorter grass shortcut when its actual presentation travel cost is lower.
- Standing Playthings and persistent structures contribute physical navigation obstacles so routes do not knowingly cross their occupied footprints.
- Very saturated one-cell road corridors receive a bounded capacity penalty so later traffic may spread into nearby lanes/junctions rather than all paths collapsing indefinitely onto one exact line.
- Isolated wear remains ground/apron presentation rather than being promoted into fake infrastructure solely because its local count is high.
- Playthings Lineage Verse orders current/latest at the top and lets Parent ancestry fall downward toward the oldest/root artifact at the bottom, matching normal Tiinex lineage reading direction.
- Clicking Playthings mounts a paintable Verse/loading shell before material projection begins.
- Loaded workspace material is compacted cooperatively with browser yields before worker handoff.
- Current browsers prepare Tiinex projection, living/history planning, world generation, A*/roads, and resting/place state in a module Worker rather than synchronously inside React first render.
- Worker progress is surfaced through a Playthings fantasy loading screen/progress bar; refreshing an already-open Verse may keep the prior snapshot visible with a compact background progress indicator.
- Unsupported-worker fallback still yields before preparation, while no claim is made that the fallback can provide the same main-thread isolation as the worker path.
- Existing synchronized fork choreography, sleeping-location inspection, stable actor identity, Find/LOCAL attribution, Tech Tree, canonical Create/transition authority, DnD/reconciliation behavior, and package semantics remain intact.
- Playthings cases, TypeScript, architecture, browser imports, UI shape, smoke, integration, and static regression qualification pass with zero introduced static debt.
