# Pilot-Mediated UAL 8x8 Locomotion Master Generation

## Objective

Execute one bounded human-mediated image-generation attempt using a deterministic 8x8 motion/direction authority and one accepted Plaything identity authority, then return the exact generated source and execution evidence to Anchor for 64-cell technical and motion review.

## Done Criteria

- Pilot grounds from the generic Business Pilot Role and Human-Mediated External Execution process.
- Pilot identifies the two exact carried inputs by filename, SHA-256, order, and declared authority role.
- The human receives decision-minimal instructions and the exact carried user-visible input without reconstructing hidden chat history.
- One external generation attempt is executed with the motion/direction authority first and identity authority second.
- Pilot preserves the exact returned generated bytes when exposed by the host and records actual input identities, actual human-visible input, confirmation steps, provider/host anomalies, and preservation limits.
- Pilot does not judge visual quality, repair the sheet, normalize cells, or promote an output.
- Pilot writes execution Evidence and a Pilot-to-Anchor return Handoff as descendants of this Task; lineage-local transient outputs share the Evidence lineage stem where practical.
- Pilot manufactures a qualified return Handoff package immediately after success or a bounded blocked outcome.

## Scope

One full 8x8 locomotion master generation attempt only. The Task tests deterministic authority carriage and Pilot execution at 64-slot scale. It does not freeze a universal sprite-sheet schema, redesign the Plaything identity, or establish acceptance merely because generation returns.
