# Playthings multiverse experiment for a read-only spatial projection of Tiinex repository lineage.

## Objective

Create an isolated Site experiment that projects each loaded repository as a bounded Verse and resolved lineage as original 8-bit inhabitants, while keeping Tiinex artifacts, lineage resolution, and source boundaries authoritative.

## Done Criteria

- The experiment is opt-in and does not replace or mutate the normal Viewer surface.
- One loaded repository projects to one bounded Verse; loaded resolved cross-repository Parent continuity projects as an explicit portal between Verse boundaries.
- Spatial position, sprite choice, and animation remain presentation state only and never become Parent, Relation, provenance, truth, or execution authority.
- First observation is still; refresh reuses the existing Site source path; only newly observed resolved delta is replayed; reaching Now returns the world to stillness.
- Missing or ambiguous lineage remains unresolved rather than being inferred.
- The concrete visual language is original 8-bit Tiinex expression and does not reproduce Black Mirror/Thronglets assets, branding, characters, UI, sounds, or story material.
- No Business or Docs repository artifact is created or modified by this Task.

## Scope

- Tiinex/site only, on top of the current refactor architecture.
- Read-only multiverse projection, deterministic delta planning/playback, repository Verse boundaries, Parent-lineage inhabitants, cross-Verse Parent portals, and focused tests.
- A URL-gated experimental entrypoint is acceptable for this slice.
- PixiJS remains an optional later renderer if scale or interaction warrants it; this Task first proves semantic/playback behavior with the smallest reversible rendering surface.
- Typed non-Parent relations, authoring, semantic drag/drop, simulation, autonomous agents, and merge/promotion to the normal Viewer are out of scope.
