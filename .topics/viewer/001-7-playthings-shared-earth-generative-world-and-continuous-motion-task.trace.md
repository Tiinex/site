# Playthings shared-earth generative world and continuous motion refinement

## Objective

Implement the co-designed shared-world model: all loaded workspaces/origins coexist on one earth; nothing permanent exists without observed history; artifacts act as scenes or consequences rather than automatic world icons; deterministic nearest-free placement grows from current context; roots spawn, sibling branches fork from the living leaf, handoff receivers may emerge from already-built Organization places, and playback runs as continuous frame-sampled movement rather than event-to-event slideshow transitions.

## Done Criteria

- All loaded workspaces and cross-origin lineage material coexist on one shared earth; repo/workspace identity does not create separate islands or semantic geography.
- Blank playback begins with presentation terrain only: no prebuilt castle, road, station field, portal corridor, or other history-implying permanent structure.
- Persistent structures appear only when an observed artifact companion explicitly permits persistence and the active Plaything visibly constructs/materializes that consequence during playback.
- Organization remains the only automatic persistent structure in this refinement; consecutive Organization lineage depth may vary settlement morphology without implying rank, value, or authority.
- Task and other non-persistent artifacts are active scenes/interactions; their artifact files do not need permanent clickable objects in the world.
- Placement is prefix-stable and deterministic: each new scene searches nearest valid free presentation space from the relevant Plaything/branch context with deterministic seed-derived scan direction and stable tie-breaking.
- Later suffix history does not relocate already-generated earlier world positions; retroactive lineage/history/input change may legitimately generate a different projection.
- Root events spawn a Plaything; first-child continuation moves the same living leaf; later siblings preserve the existing leaf and create a new travelling branch that can return through the actual branch point before seeking its own free scene location.
- A Handoff companion requesting an organization receiver may originate the receiving Plaything from the nearest already-built Organization spawn context and visibly travel to the Handoff scene.
- Playback cursor represents completed events; the next event remains a continuous active sequence until its travel/interaction/settle phases finish.
- Movement is sampled through requestAnimationFrame with distance-aware bounded timing, smooth acceleration/deceleration, walking bob, directional facing, anticipation, arrival interaction, split feedback, construction growth, and action texture rather than integer event-step animation.
- Pause freezes an in-progress active sequence and resume continues it; scrub/Origin/Now reset to deterministic event boundaries without mutating Tiinex.
- Settled Now remains completely still: local action loops exist only while an observed active event is playing.
- Stable Tiinex self-integrity/identity material may provide namespaced deterministic presentation entropy for scan direction, body variant, and a finite shirt palette; generated values have semantic authority none and are never written back.
- Lineage hover/Tesseract remains an on-demand historical projection; parents/history need not permanently clutter the living world.
- Implementation stays decomposed across model, world generation, seed/entropy, motion planning, timeline/observation, camera, presentation companions, artwork, and renderer seams rather than introducing a Playthings monolith.
- Business and Docs remain unchanged context; Viewer persistence repair, GitHub source-adapter repair, production promotion, and canonical Playthings schema promotion remain excluded.

## Scope

- Tiinex/site Playthings experiment only.
- Shared-earth deterministic world generator and nearest-free growth placement.
- Continuous frame-sampled event motion and active-scene choreography.
- Deterministic presentation entropy and finite sprite palette/variant use.
- Existing observation cache, camera, timeline, Tesseract, global Playthings activation, and presentation companions only where needed for integration.
- Focused architectural/type/smoke validation and Anchor-to-Anchor manual-test Handoff package.
