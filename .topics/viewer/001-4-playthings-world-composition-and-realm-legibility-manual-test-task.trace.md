# Improve Playthings realm legibility and fantasy-world composition after manual testing showed correct multi-realm mechanics but excessive density and weak world personality.

## Objective

Respond to Tiinusen's third manual test and Glimmer's advisory feedback: preserve the successful read-only multiverse, evidence-backed gates, uncertainty, and delta-only movement while making the projection read as a coherent 8-bit fantasy/reality world rather than a crowded artifact board.

## Done Criteria

- An unambiguously configured repository remains a visible realm even when currently loaded records do not produce lineage heads; realm presence must not depend on successful GitHub discovery or arbitrary minimum lineage density.
- Newly observed repository realms participate in delta playback before Now settles again.
- Current lineage heads remain represented, but morphology follows the existing artifact visual grammar: task/relic-like heads may appear as inhabitants while structural heads such as project, discovery, handoff, evidence, workspace, decision, and relation materialize as structures/landmarks rather than identical creatures.
- Historical lineage remains visible as bounded memory/trail language instead of rendering every historical artifact at equal visual weight.
- Inhabitants and structural heads use deterministic non-overlapping district placement rather than hash-cloud coordinates; spatial placement remains presentation only.
- Tiinex/business, Tiinex/docs, and Tiinex/site retain distinct original realm hearts/scenery and are laid out as separate worlds; Docs may appear as a quiet Archive realm even when lineage resolution is sparse.
- Multiple resolver-supported Parent crossings between the same pair of repository Verses project as one geographical gate route with an explicit count rather than overlapping identical bridges; individual underlying edges remain preserved in the model.
- No ambient movement is introduced. Settled Now remains still; only newly observed realm/artifact/gate delta animates, with reduced-motion respected.
- No visual road, district, scenery element, sprite, or gate count becomes semantic authority or invents a relation.
- Business and Docs repositories remain unchanged context; GitHub adapter repair and Viewer persistence remain outside this Task.

## Scope

- Tiinex/site Playthings experiment only.
- Model support for configured-but-lineage-quiet realms and realm delta events.
- Original world composition, semantic morphology, deterministic districts, calmer lineage-memory rendering, gate aggregation, and focused tests.
- Preserve direct Feed/Tree → Playthings activation and read-only refresh behavior.
