## Manual Test Frontier

- Load the same representative ZIP/workspace material and enter global Playthings. Confirm every origin still lives on one earth with no repository/workspace islands.
- Replay from Origin and judge placement first: populations should grow irregularly and locally rather than reading as rows, circles, square rings, or a graph layout. Replay unchanged material and confirm the geography remains identical.
- Observe children beneath Organization/Workspace places: proximity may influence nearby growth, but children should still use free organic space rather than stack on a fixed ring or snap to the building.
- Watch sibling split behavior with multiple siblings: the existing leaf remains present; the new Plaything should not collide with it and should visibly move through branch context before establishing its own scene.
- Toggle Follow during playback. While the active Plaything travels, camera center should track it smoothly; wheel zoom remains available and manual pan is suppressed only while Follow is actively locked. Pause should release that active lock.
- Use Fit World at sparse and populated points in history. It should frame visible content rather than the full empty 2200×1350 earth and should not expand for Playthings currently resting inside a settlement.
- Click a living Plaything and a built Organization/Workspace place. The owning artifact should open in the existing detailed Viewer surface; camera drag must not consume the click.
- Pause playback at a historical event. Confirm Tech Tree, Skills, and hotbar appear while historical playhead time stays at the current artifact event.
- Inspect Schema Tech Tree: Site-known schemas appear implemented; observed schema artifacts absent from Site appear locked / not yet implemented but remain Open-able when loaded; abstract Root cannot yield a Create skill.
- Use normal Open→Upgrade on a creatable schema, then hold Shift on another upgradeable schema to confirm quick-upgrade bypasses only the Playthings Open friction.
- Put unlocked skills on the hotbar by click/drag; trigger them by click and number keys and confirm the existing canonical Create dialog opens rather than a Playthings-specific form.
- While paused or Live, hover a leaf that has a Viewer-qualified transition matching an unlocked skill. The small transition menu should show only valid/unlocked options and invoke the existing record action/create path.
- Create an artifact while paused in historical playback. Confirm creation uses real current time and is treated as later/Now suffix material, not inserted at the historical playhead timestamp.
- Create an artifact while Live. Confirm the new suffix may transition from Live into playback and return to Live/Still once the new event reaches Now.
- Observe a Signal event: it should read as a call with expanding ripple rings while active, not an invented receiving Plaything. Pause mid-Signal and confirm the ripple freezes too.
- Observe Feedback and other companion scenes and confirm no participant/object is fabricated solely for visual completeness.
- Inspect a Workspace artifact event: its workshop/hamlet must build during history rather than pre-exist; multiple houses require bounded actually represented Workspace material.
- Move the timeline across the inactivity thresholds. A leaf should be normal before four relative days, visually long-idle from four through seven, and after seven days should rest in the nearest already-built legitimate habitat when one exists. If later history continues the leaf, it should wake/re-enter activity.
- Reach Now. Confirm state changes to Live · Still, no autonomous walking continues, and hotbar/Tech Tree remain available for current-time actions.
