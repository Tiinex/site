- First: rebuild/confirm the current Playthings causal baseline in code: schema exclusion, living leaves, resting continuity, structure footprints, roads/navigation, Follow/Fit, and non-blocking Verse entry where absent.
- Second: introduce a small runtime sprite-atlas renderer with exact manifest/frame/pivot/alpha rules and replace only one Plaything + Root Tree slice before broad asset replacement.
- Third: implement Root Tree clearing/entrance sockets, correct Z-order, and Born/Expire-to-nothingness transitions so the shared overworld has no obvious popping/road-over-building bugs.
- Fourth: implement Journey Reason Resolver before adding new actor-to-Place travel. Use it for Workspace construction and schema Library journeys.
- Fifth: implement Place scene stack, door/stair transitions, Follow across scenes, and a generative Habitat interior whose bed count proves capacity scaling from actual sleeping residents.
- Sixth: generalize the same scene/capacity system to Workspace/Library/Organization and nested Place lineage floors/departments.
- Seventh: return Playthings to fullscreen with floating HUD and tune roads/visual density/art direction from actual browser recordings.
- Artifactize each meaningful checkpoint as Evidence and hand off only after source/runtime claims have exact receipts.

## Manual Test Frontier

- Verify entry remains responsive before judging new art; no 20-30 second dead-tab regression is acceptable.
- Confirm normal artifacts visibly Born and Expire rather than pop/blink; after Expire the default visual is gone.
- Confirm a Workspace event visibly causes a Plaything to travel for a grounded reason and build the justified workspace representation rather than the building appearing fully formed.
- Follow an actor through an exterior door, fade, interior scene, stairs/child Place, and back out; the camera should keep the same actor identity through the scene stack.
- Create/observe a Habitat with different resting counts and confirm generated sleeping capacity follows actual count rather than a pre-furnished room picture.
- Inspect a Place quickly via Look Inside and compare with full Enter; both should use the same world state but different navigation commitment.
- Observe nested Place lineage and verify building/floor/department projection follows actual Parent structure without inventing absent child Places.
- Verify schema documents remain nonliving blueprints and that any Library storage trip has an explicit presentation reason and never rewrites lineage.
- Verify roads approach entrance sockets/clearings, remain under tree/building cores, mature through repeated travel, and begin forming shared trunks rather than radial spokes from one exact point.
- Verify true steampunk art direction: physical steam/mechanics/DC instruments, no transistor-era devices, no unexplained magic power technology.
- Verify Follow, Fit, Tech Tree, Find, hotbar, artifact detail, DnD/Handoff reconciliation, fork choreography, sleeping Look Inside, and Live/Still behavior do not regress.
