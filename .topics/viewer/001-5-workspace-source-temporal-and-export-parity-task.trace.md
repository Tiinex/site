# Viewer Workspace, Source, Temporal And Export Parity

## Objective

Recover or explicitly disposition PoC intake, Workspace lifecycle, source materialization, local persistence/recovery, Time Portal, diagnostics, export, publication, and re-ingest behavior from shared qualified runtime contracts.

## Done Criteria

- Local/archive/paste/source intake reports conflicts, degraded transport, password needs, and source authority truthfully.
- Workspace Open/Merge and source-over-import takeover preserve durable unpublished local work and do not create duplicate hidden authority.
- Refresh/recovery keeps local deltas distinct from disposable route/source cache and does not hydrate unrelated stale state into a cold target.
- Time Portal resolves explicit historical source intent to immutable representation without mutating current/latest truth or fabricating a commit from a date.
- Ordinary Tree ZIP and qualified Handoff package remain separate product paths with truthful file-map/manifest/receipt boundaries.
- Publication remains explicit preflight/confirm/verify with exact targets; source-backed input remains reference/source truth rather than local authorship.
- Equivalent state, source, historical, export, and diagnostics contracts are inspectable/qualifiable through Tooling before browser parity is claimed.

## Scope

- Planned implementation. Host/network availability is reported as degraded/blocked evidence rather than converted into product success or failure by guesswork.
