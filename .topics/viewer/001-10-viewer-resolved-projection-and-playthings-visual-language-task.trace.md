# Viewer resolved projection and Playthings visual language refinement

## Objective

Continue the post-stability Playthings checkpoint as an impress-and-performance pass rather than adding new semantic features: cache material-derived Viewer projections across unrelated UI changes; make Feed transition qualification interaction-lazy; avoid repeated source-cache hydration scans; improve Handoff workspace display names; remove schema artifacts from the living-Plaything population; make role identity visually stable through deterministic hats; replace the indented Tech Tree list with a tiered blueprint surface whose implemented-only filter is enabled by default; make active history events easier to locate; and further reduce the single-rosette appearance of deterministic world growth.

## Done Criteria

- Viewer material-derived discovery/audit projections are reusable by workspace material identity rather than recomputed because another column receives focus or unrelated view state changes.
- Workspace transition product context is cached by workspace-record/reference-record material identity and is not invalidated by active-workspace focus alone.
- Feed cards do not qualify transition products for every visible artifact during ordinary render; a card arms its transition actions only on pointer/focus interaction.
- GitHub/source-backed record UI hydration reuses positive results and briefly remembers negative cache misses so repeated UI state changes do not rescan localStorage for every record.
- These Viewer caches are presentation/performance caches only and do not replace Tiinex lineage, transition, schema, source, or persistence authority.
- Recipient-v2 Handoff workspace artifacts produce meaningful display titles from their actual Workspace artifact headings, including Tiinex Business, Tiinex Docs, and Tiinex Site for the current package, instead of repeating a generic Browser Title.
- Schema artifacts remain historical blueprint events and Tech Tree material but never become living Plaything actors or occupy the earth as living leaves.
- Schema ancestors shown through Tesseract history use blueprint echoes rather than ghost Playthings.
- A resolved role identity produces one deterministic hat silhouette and hat color shared by every Plaything carrying that same role; individual shirt/body presentation may still vary independently.
- Role livery is inherited through the living lineage from the nearest explicit role/Authors material when the current leaf omits it; role appearance remains presentation only.
- Idle/resting presentation does not overwrite role hats; inactivity may use pose/eye/body-language details instead.
- Tech Tree opens with an Implemented only toggle enabled by default, hiding schemas unavailable in the current Site build while preserving their real topology in the full tree model.
- Disabling Implemented only reveals observed unavailable schemas as locked/ghosted nodes that remain Open-able when their artifact is loaded.
- Filtering never rewires a child to an invented visible parent; a hidden real ancestor is represented as a hidden-ancestor connector/hint.
- Tech Tree uses actual schema Parent depth as horizontal tier columns, with explicit IMPLEMENTED / CREATE CAPABLE / ABSTRACT / NOT IN SITE and local INSPECTED / UPGRADED states.
- Existing Open -> Upgrade, Shift quick-upgrade, localStorage profile, inventory, hotbar, and canonical Tiinex Create rules remain unchanged.
- Active playback receives a bounded source/event focus pulse so dense worlds show where the current event is occurring; paused playback freezes this animation with the rest of the active sequence.
- Schema playback HUD identifies blueprint observation instead of claiming a root/living leaf appeared.
- Same-role hats remain present during active traveller choreography even when the current artifact inherits role livery from its lineage.
- Independent root growth and nearest-free candidate selection use deterministic irregular frontier candidates and density/reach scoring rather than a single center/ring acceptance pattern; same history/seed remains reproducible and prefix-stable.
- Organization/Workspace places remain soft spatial incentives rather than hard containment or semantic ownership.
- No new GitHub fetch loop, qualification system, invented relation, historical timestamp, or Playthings semantic authority is introduced.
- Static regression qualification reports zero introduced debt; new helper modules are split rather than raising monolith limits.
