# Viewer Artifact And Action Parity

## Objective

Recover or explicitly disposition PoC artifact detail/provenance comprehension and canonical Create, Continue, Reference, and Use-as interaction without ad-hoc Viewer semantics.

## Done Criteria

- Artifact detail remains readable through exact schema companions where present and safe Root fallback otherwise.
- Parent, Origin, Relation/reference, evidence state, and byte/integrity status are not collapsed into stronger claims.
- Create/Continue/Reference/Use-as actions project canonical Tooling/schema creation contracts and block when the required authority is unavailable.
- Generated Markdown remains reviewable before durable mutation where the product contract requires it.
- Source artifacts remain unchanged unless an explicitly qualified operation says otherwise.
- Equivalent creation/read results and validation findings are reproducible through Tooling before Viewer parity is claimed.

## Scope

- Planned implementation; no broad schema authoring expansion is authorized by this task.
