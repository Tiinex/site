# Plaything Visual Source Production

This Site process specializes the domain-neutral Business visual-source process for Playthings identity/source bundles while preserving Playthings organizational Parent continuity.

## Current Read

The current candidate process separates image-model imagination from deterministic asset processing. A bounded source board carries one identity as FRONT, LEFT, BACK, and eight LEFT-walk poses. The board is visual source, not a runtime sprite sheet and not a final schema/artifact presentation contract.

Carrier Major 003 produced proof-of-two material for a silver-haired explorer and a mechanically different robot, plus cross-board pressure evidence. The technical checkpoint remains under `reference/playthings/production/carrier-003/board-first-v05/`. Process acceptance remains a Sigma human gate; package delivery alone is not acceptance.

## Design Direction

Run new identities through an explicit visual-boundary gate, generate one bounded identity bundle while the identity lane is coherent, accept or reject the board atomically, freeze accepted source bytes, extract and normalize locally, then review motion using an ordered pose/contact representation as the primary gait surface and animated playback as secondary temporal evidence.

Keep final world/interior/companion/detail sizes, schema/artifact sheet families, grid architecture, fullscreen behavior, time presentation, state vocabulary, and exporter layouts downstream. Those requirements may change without redefining accepted source-board bytes.

The domain-neutral Business process is reusable guidance, not this artifact's Parent: `business::.topics/processes/004-bounded-generative-visual-source-production-process.trace.md`.
