## Decision

- Subject: Evidence-over-Preservation structural inheritance and Decision orienting-body representation authority.

- Decision repair: existing Root `Required Shape` machine-contract authority is sufficient; no new schema family, Root creation behavior, section contract, or Decision-specific renderer is needed. In canonical `tiinex.decision.v1` under `Artifact Creation Contract -> Template Body -> Required Shape`, replace `summary sentence placeholder below the title` with the exact reusable structural primitive `non-empty unheaded prose block after the first body heading and before the first second-level section`.
- Decision rule clarification: the required unheaded prose block may contain one or more human-readable sentences and may be authored content or placeholder guidance; exact lexical wording is not contract authority. The primitive owns only presence, non-emptiness, unheaded representation, and placement.
- Factory primitive identity: Loom may compile that exact structural requirement once as a generic body-prose-block representation primitive. The compiler must not key behavior to `tiinex.decision.v1`, infer exact prose, reinterpret the block as a section, or satisfy it with envelope metadata.
- Canonical status: these repairs are semantically qualified proposals in this return. Because this Handoff does not authorize remote Docs publication and the current cross-workspace carriage seam does not provide a writable canonical Docs continuation, the canonical source files are not claimed as mutated or landed in this turn.

## Basis

- Root makes descendant requirements additive by default and requires explicit override semantics identifying the inherited requirement replaced and the replacement interpretation; canonical `tiinex.schema.inheritance.v1` already defines the required `override` merge operation, Parent Node, Child Node, Effective Result, and fail-visible conflict policy.
- Evidence explicitly says its body sections replace the generic Preservation body while retaining Preservation specialization semantics. The missing authority is therefore structural merge representation, not a reason to copy parent semantics, introduce global child precedence, or add an Evidence-specific compiler exception.
- Root already makes `Required Shape` part of the machine-authoritative contract syntax. The Decision defect is that its current creation shape uses a vague template-specific phrase even though the normative rule requires a structural unheaded orienting sentence before the first named section.
- Schema Section explicitly says not to create a section contract for a one-off paragraph with no reusable section role. Treating Decision orientation as a section would therefore manufacture the wrong semantic object.
- Machine Shape Definitions are lexical scalar-shape authority and do not reinterpret historical `Required Shape`; using them for a document-position body block would conflate lexical value shape with structural representation.
- A normalized exact `Required Shape` literal is the smallest canonical repair that preserves Root abstractness while giving deterministic tooling one reusable structural primitive.
