## Transfers

- shared-lifecycle-readiness-evaluator
  - Transfer Kind: work-and-responsibility
  - Description: implement one shared Site/Tooling evaluator for one exact qualified controlling Task with separate `readiness`, `retest`, and `closure` surfaces under the accepted Axiom/Anchor contract. The normalized result must preserve the exact controlling Task, current representatives, basis, reasons, blockers, missing evidence, ambiguities, authority basis, and bounded next action.
  - Controlling Artifact: [Anchor Semantic Reconciliation](021-2-anchor-major-010-lifecycle-readiness-semantic-reconciliation-decision.trace.md)
  - Boundary: projection-only runtime semantics; do not persist derived readiness as canonical artifact truth or create a new Root Status vocabulary.

- fail-closed-currentness-and-authority-resolution
  - Transfer Kind: work-and-responsibility
  - Description: derive in-scope work/current representatives only from qualified Task continuity and already-declared typed work/provenance semantics whose meaning applies. Preserve missing/ambiguous/contradictory lineage, representative selection, criterion coverage, or authority as `unresolved`; do not normalize uncertainty to a positive or negative readiness claim.
  - Controlling Artifact: [Axiom Semantic Disposition](021-1-1-1-axiom-major-010-lifecycle-readiness-semantic-disposition-decision.trace.md)
  - Boundary: Parent remains direct continuity; no generic dependency/readiness meaning from arbitrary ancestry, filenames, timestamps alone, branch state, or lexical labels.

- authoritative-retest-and-closure-projection
  - Transfer Kind: work-and-responsibility
  - Description: project `retest` pass/fail only from a qualified explicit outcome targeting the controlling criteria under the correct acceptance/validation authority, and project `closure.closed` only from a qualified explicit governing closure whose basis includes/incorporates an authoritative pass. A passing re-test with no closure artifact remains `closure.open`.
  - Controlling Artifact: [Axiom Semantic Disposition](021-1-1-1-axiom-major-010-lifecycle-readiness-semantic-disposition-decision.trace.md)
  - Boundary: authorship, human presence, report existence, Root `Status`, or agreement of content never repairs authority mismatch.

- reduction-as-bounded-representative-evidence
  - Transfer Kind: work-and-responsibility
  - Description: allow a qualified Reduction/current representative to satisfy only the re-test-input availability side of readiness when its declared carry-forward/loss/validation boundary preserves what the parent criteria require. Material unknown loss must remain unresolved; positively known missing required input may produce not-ready.
  - Controlling Artifact: [Anchor Semantic Reconciliation](021-2-anchor-major-010-lifecycle-readiness-semantic-reconciliation-decision.trace.md)
  - Boundary: no Reduction composition, reduction-of-reductions, destructive apply/delete, cleanup authority, recovery widening, or cross-repository collapse.

- permanent-neutral-regressions
  - Transfer Kind: work
  - Description: add durable suite-owned neutral regression coverage for the accepted lifecycle contract, including failed criterion/child expansion, unresolved required descendant, convergence-before-retest, pass-with-open-closure, explicit closure, failed retest/new work, missing/ambiguous lineage, stale historical nonterminal evidence superseded by qualified current evidence, Reduction-as-noncompletion representative, material Reduction loss, and authority mismatch.
  - Controlling Artifact: [Major 010 Task](021-artifacted-work-lifecycle-readiness.task.trace.md)
  - Boundary: prefer existing Foundation/focused suite ownership; do not create a parallel consumer-specific or app-specific lifecycle truth model.

- shared-consumer-boundary
  - Transfer Kind: responsibility
  - Description: keep the normalized evaluator adapter-neutral and callable by CLI, LLM, Viewer, and VS Code paths without those consumers independently recomputing readiness. It is sufficient in this tranche to expose the shared Tooling contract and prove neutral consumption boundaries; do not enter Viewer presentation work.
  - Controlling Artifact: [Anchor Semantic Reconciliation](021-2-anchor-major-010-lifecycle-readiness-semantic-reconciliation-decision.trace.md)
  - Boundary: no Viewer/Playthings transfer, parity polish, UI redesign, deployment, or release.

- bounded-technical-qualification-and-return
  - Transfer Kind: work-and-responsibility
  - Description: run the narrow-to-broad technical qualification appropriate to the changed owners, including the new permanent neutral cases, focused Tooling/Foundation coverage, architecture shape, typecheck, integration, and static diagnostic evidence. Return one canonical full-source Business+Docs+Site non-major Handoff Package to Anchor before public process reconciliation or Major closure.
  - Controlling Artifact: [Major 010 Task](021-artifacted-work-lifecycle-readiness.task.trace.md)
  - Boundary: return technical evidence and residual blockers exactly; do not claim Major 010 closure or remote publication.
