# Sigma Human-First CLI Output-Cost Feedback

## Observed Signal

- Sigma observed the fresh zero-precontext Loom acceptance run and judged the post-takeover Tiinex interaction visibly expensive in token/output volume even though the run no longer needed bespoke Tiinex navigation or protocol glue.
- The same fresh Loom run took roughly seven minutes wall time. A preceding informal Sigma runtime observation had seen roughly eight recent Anchor/Loom turns stay at or below about six minutes; this new timing is retained only as a metric and does not establish causality.
- Anchor replayed the returned carrier through the declared public path and measured raw default terminal output before any author/handoff result: `orient-handoff-package` emitted 15,183 bytes across 331 lines; `ground` emitted 19,826 bytes across 384 lines; and `ground --continue` emitted 78,991 bytes across 408 lines. These are raw output-volume measurements, not token counts.

## Source

- Source: direct Sigma observation of the supplied fresh Loom screen recording and runtime duration, plus Anchor replay of the exact returned carrier through the carried public Tooling bootstrap.

## Interpretation

- Interpretation: the fresh technical no-glue acceptance remains meaningful. The common path now owns package navigation, grounding, continuation, integrity, staging, and carrier manufacture instead of forcing caller-side protocol scripts.
- Interpretation: the human-first CLI goal is nevertheless not closed. Default common-path rendering remains too receipt-heavy: ordinary orientation/grounding/continuation exposes large machine-oriented projections whose volume is disproportionate to the human or LLM decision needed at that step.
- Interpretation: this is a presentation/progressive-disclosure defect unless Loom's reproduction proves a deeper semantic dependency. The correction must not create separate human and LLM command surfaces.

## Feedback Target

- Target: default output projection and progressive disclosure for the existing public common path, especially `orient`, `ground`, and `ground --continue`, with follow-through to ordinary `author`/`handoff` result rendering where the same defect is reproduced.

## Feedback Received

- Keep one public CLI surface with the same commands, defaults, and output contracts for humans and LLMs.
- The default output should answer the immediate use case first: state, authority/role needed for the next decision, current Task, Required Context closure, continuity/blocker state, materialized Workspace/result identity when applicable, and one exact next action.
- Full operation receipts, internal projection detail, diagnostic lineage structures, hashes, transport maps, and other deep evidence may remain available through deliberate detail/debug discovery, but should not be dumped by default on the happy path.
- Do not trade away fail-closed semantics or provenance proof merely to reduce text. Compact output may summarize qualified proof while retaining the full receipt internally or behind an explicit detail option.
- No exact token-saving target is asserted yet. The requirement is a materially smaller, recognizable ordinary path that can be measured on the same acceptance carrier without losing information required for correct next-action decisions.

## Disposition

- State: accepted
- Follow-Up: Anchor should hold carrier-major `007` human-recognizability acceptance, route one bounded Loom correction focused on default common-path output density/progressive disclosure, and repeat fresh acceptance only after the correction is independently qualified.

## Limits

- This feedback records output volume and human recognizability; it does not claim that Tooling caused the observed wall-time change, nor does it establish model token billing or hidden host reasoning cost.
- This feedback does not reopen artifact semantics, Handoff package topology, grounding/recovery integrity, Viewer/Extension work, remote mutation, or a second LLM-specific interface.
- Advanced/debug output remains legitimate when deliberately requested. The failure is requiring receipt-scale output as the ordinary default path.
