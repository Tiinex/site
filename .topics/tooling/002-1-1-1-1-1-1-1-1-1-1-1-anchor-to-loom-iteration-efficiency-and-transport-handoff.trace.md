## Transfers

- fast-validation-spine
  - Transfer Kind: work-and-responsibility
  - Description: make routine Tooling iteration use a small truthful validation spine with explicit smoke/focused/integration/closure purposes; remove, demote, or replace duplicated/historical/host-sensitive tests only after the invariant they protect is understood and retained through cheaper representative coverage

- end-to-end-acceptance
  - Transfer Kind: work-and-responsibility
  - Description: prefer a small fast end-to-end acceptance set that covers real Foundation use cases across cold start, bounded work, return transport, and stable-major qualification rather than accumulating broad regression inventory whose individual checks do not materially improve confidence

- canonical-zip-bootstrap
  - Transfer Kind: work-and-responsibility
  - Description: harden bootstrap/manufacture so one logical role-to-role transport has one recognizable canonical Tiinex ZIP shape, exact endpoint Role material, qualified inner structure, predecessor continuity, and fail-closed dependency resolution; an arbitrary ZIP wrapper must never qualify as Tiinex transport

- integrity-and-receipt-simplification
  - Transfer Kind: work-and-responsibility
  - Description: profile receipt.json, compatibility projections, repeated hashing, and repeated byte-equivalence checks; move semantic authority back to qualified artifacts/pointers/representations and retain only the minimum integrity verification needed at real mutation/trust boundaries

- return-first-discipline
  - Transfer Kind: work-and-responsibility
  - Description: keep each lane independently returnable and manufacture a recoverable canonical carrier before entering broad/long closure; do not spend the host turn budget retrying the same expensive path after a bounded result is already durable
