## Transfers

- tranche-a-byte-recovery
  - Transfer Kind: work-and-responsibility
  - Description: recover the already-completed Tranche A modified Site bytes from the current Loom runtime if those bytes are still available, without redoing the accepted implementation, and use them as the Site root for one canonical return manufacture
  - Controlling Artifact: [Static Closure Debt Tranche A — Anchor Return](002-1-1-1-1-1-1-1-1-1-loom-to-anchor-static-closure-debt-tranche-a-return-handoff.trace.md)

- canonical-carrier-retry
  - Transfer Kind: work-and-responsibility
  - Description: manufacture the recovery return only through canonical Tiinex Handoff tooling using complete carried Business and Docs source plus the recovered current Site source, then qualify the resulting carrier before exposing it to the human transporter
  - Controlling Artifact: [Static Closure Debt Tranche A — Anchor Return](002-1-1-1-1-1-1-1-1-1-loom-to-anchor-static-closure-debt-tranche-a-return-handoff.trace.md)

- transport-shape-pre-send-gate
  - Transfer Kind: work-and-responsibility
  - Description: treat canonical manufacture, orientation, context audit, route qualification, and projected human output as a mandatory pre-send gate for this and future Loom transports
  - Controlling Artifact: [Static Closure Debt Tranche A — Anchor Return](002-1-1-1-1-1-1-1-1-1-loom-to-anchor-static-closure-debt-tranche-a-return-handoff.trace.md)

- Signal Meaning: Loom either returns one Tooling-manufactured and Tooling-qualified canonical full-source Business + Docs + current Site ZIP carrying the recovered Tranche A implementation, exact endpoint Role material, durable Evidence/Handoff, and executable route; or, if the current Tranche A modified Site bytes are no longer available, returns one bounded blocked recovery result that names that single missing material truth without substituting remote or inferred bytes

## Interpretation Limits

- Does Not Mean: Tranche A must be redone, the seven remaining static findings are accepted, iteration-efficiency work has already begun, final closure passed, stable/major qualification is implied, or host safety behavior is controlled by Tiinex
- Must Not Be Used To Claim: that any `.zip` attachment is a Tiinex carrier, that warm-session source can silently substitute for required carrier bytes, that remote checkout is continuity-equivalent to carried source, or that a successful implementation excuses transport-convention failure
- Authority Limits: Loom owns bounded Tooling execution and recovery manufacture; Anchor owns cross-role architecture/transport disposition; Axiom retains canonical semantics; Sigma retains human workflow observation and acceptance
