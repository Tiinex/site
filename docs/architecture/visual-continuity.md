# Visual Continuity

v94 introduced the visual continuity principle. v95 treats the archived app as the visual pattern baseline.

The goal is not to copy the old monolith, but to preserve the fast-recognition language that made it usable:

- a centered Tiinex workspace window,
- compact top dock actions,
- stable source and mode rows,
- status chips as quick pattern anchors,
- artifact cards with familiar badge/title/action rhythm,
- diagnostics behind disclosure instead of primary dashboard cards,
- icon-first recurring actions,
- prose only where it carries variable trust, source, risk, or lineage meaning.

## Mobile lesson

The old mobile flow proved that Tiinex cards and action sheets can work on small screens, but it also overused text and duplicated controls. New mobile work should keep value first, controls second, avoid redundant camera/file choices, and keep the primary action sticky only when it is truly primary.

## Transport lesson

Remote/transport behavior should be a first-class adapter boundary, not a hidden share/export side effect. Transport must preserve source, checksum, parent, and degraded-state context when material is sent elsewhere.
