# Presentation Surfaces

Presentation surfaces are bounded places or modes where artifact material is shown, selected, edited, audited, or summarized. Feed, tree, detail, lineage, preview, share, create, edit, display-options, source-settings, and audit report are surfaces; they are not schema truth.

Schema modules provide surface-specific presentation models when useful. Surfaces render those models and disclose truncation, fallback, unavailable validation, or missing module behavior.
