# Source Settings And Discovery Controls

v89 keeps the source boundary visible while reducing explanatory text in the primary workspace.

## Controls

- Feed and Tree arrange the same loaded artifact set.
- Reader modes change density, not truth.
- Source filters limit what is shown, not what is true.
- Search filters loaded material in memory.
- Audit remains an explicit command.

## Source Boundary

Local files, draft/pasted text, and static fixtures must not become GitHub source-backed material by inference. A GitHub source-backed state requires an explicit descriptor.
