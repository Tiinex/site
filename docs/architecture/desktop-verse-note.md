# Desktop Verse Note

Desktop is a planned Verse candidate, not implemented runtime in v93.

The idea is to use a familiar desktop metaphor: folders, files, windows, panes, and spatial placement over Tiinex material. Its value is human-first recognizability, not developer novelty.

Desktop may later exist at workspace or universe context:

- workspace-level Desktop: one workspace shown as folders/files/windows
- universe-level Desktop: multiple workspaces shown as drives, windows, or desktops

Desktop may use DOM/CSS, Canvas, Leaflet, WebGL, or a game-engine renderer. The renderer must remain an implementation detail.

Desktop must preserve source boundaries and must not turn visual familiarity into source, validation, or lineage truth.
