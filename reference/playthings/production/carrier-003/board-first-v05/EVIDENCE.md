# Evidence — board-first proof of two

Two visually different generated identities (explorer and robot) can be treated as atomic 3-view + 8-walk source boards and processed by the same deterministic extractor without character-specific branches.

## Qualified mechanical observation

Both primary boards pass:

- three canonical view extractions;
- eight ordered walk extractions;
- shared-strip scaling (no per-frame scaling);
- source-height-drift gate;
- current world64 non-empty cells;
- current world64 safety probe.

See `VALIDATION.md` and `validation.json` for exact checks and source hashes.

## Scope boundary

This evidence supports local segmentation/normalization generality for the current board family. It does not support artistic acceptance, semantic truth, final runtime sheet requirements, or the claim that the generated walk is perceptually good.
