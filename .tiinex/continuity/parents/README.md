# Parent recovery representations

This directory contains exact recovery representations of external Parent artifacts used by repo-local Tiinex lineage.

These files are representation material only. They do not create new semantic artifacts, do not replace the canonical source repository, and are intentionally outside `.topics/` so ordinary current-work discovery does not treat them as additional lineage nodes. A child artifact may use one of these exact bytes as its required relative Parent recovery route while its `Trace` identifies the canonical external Parent source.
